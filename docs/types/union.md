# Unions

A GraphQL union is written as a Python `Union`/`|` of the member types --
there's no separate `@bramble.union`-decorated marker type wrapping the
members themselves:

```python
from typing import Union

@bramble.type
class Query:
    @bramble.field
    def search(term: str) -> list[Union[Author, Post]]:
        ...
```

```graphql
union AuthorPost = Author | Post
```

A bare `Union[...]`/`X | Y` gets an autogenerated union name (the member
type names concatenated). For an explicit name, description, or a custom
type-resolution callback, wrap it in `Annotated[...]` with
`bramble.union(...)`:

```python
from typing import Annotated, Union

def _resolve_search_result_type(obj: object, info: object) -> type:
    if isinstance(obj, AuthorRecord):
        return Author
    if isinstance(obj, PostRecord):
        return Post
    raise bramble.GraphQLError(
        f"'{type(obj).__name__}' is not a search result type",
        code=bramble.ErrorCode.UNION_TYPE_RESOLUTION_FAILED,
    )

SearchResult = Annotated[
    Union[Author, Post],
    bramble.union("SearchResult", resolve_type=_resolve_search_result_type),
]

@bramble.type
class Query:
    @bramble.field
    async def search(term: str, info: bramble.Info) -> list[SearchResult]:
        ...
```

```graphql
union SearchResult = Author | Post
```

```python
schema.execute('{ search(term: "a") { __typename ... on Author { name } ... on Post { title } } }')
```

## Resolving the concrete type

Without a `resolve_type` callback, bramble picks the member type via a
plain `isinstance(obj, member)` check against each member, same as an
interface's default fallback. With one, `resolve_type(obj, info)` is called
and must return one of the union's own member classes -- returning anything
else raises `bramble.GraphQLError`.

As with interfaces, exactly one member must match a resolved value -- zero
or multiple matches both raise `bramble.GraphQLError` with
`code=ErrorCode.UNION_TYPE_RESOLUTION_FAILED`.

Unlike an interface, a union's members share no common base class to hang a
per-member `is_type_of` on -- `resolve_type` is bramble's own equivalent
mechanism for a union specifically.

`resolve_type` is called synchronously and cannot be `async`, matching an
interface's `is_type_of` -- see
[Resolving the concrete type](interfaces.md#type-resolution-is-synchronous) for
why, and for what to do when the discriminator is not already on the value.
